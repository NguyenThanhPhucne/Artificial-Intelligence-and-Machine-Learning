Test set. All three tuned models detect every FTP-BruteForce flow in the test set (9 of 9) and misclassify between 1 and 3 of 15,000 flows (accuracy 0.9998–0.9999; Figure 5.1). The test scores are consistent with cross-validation for accuracy and weighted F1 (Figure 5.2). For macro F1, test scores range from 0.9666 to 0.9998. The point estimate falls below one standard deviation of the cross-validated mean for Random Forest, yet every 95% bootstrap interval overlaps the cross-validated range: Logistic Regression [0.9166, 1.0000], Decision Tree [0.9996, 1.0000], Random Forest [0.9523, 1.0000]. With nine FTP flows, one false alarm lowers FTP precision to 0.90 and macro F1 by about 0.02, so the test set cannot rank the models; a model with no FTP error also gets an artificially narrow interval, because no resample can contain an FTP error.

Ablations (Figure 5.3). (a) Without de-duplication, 99.96% of FTP-BruteForce and 50.9% of SSH-Bruteforce test flows already occur identically in the training set, and the Random Forest scores a perfect 1.0000 macro F1 on that split: a naive evaluation largely measures recall of memorised rows. (b) Adding Dst Port raises cross-validated macro F1 for every model (Random Forest +0.0044, Logistic Regression +0.0123), confirming that the port is a shortcut. (c) Removing the initial window sizes changes macro F1 by +0.0000, -0.0001 and -0.0051 (LR, DT, RF), each within one standard deviation, so the models do not depend on the window size alone. The reason is visible in the tree's root split, Fwd Seg Size Min ≤ 30 bytes: this value is constant within each attack (40 for every FTP flow, 32 for every SSH flow) and plausibly also reflects the attacking host's TCP configuration. (c′) Removing it together with the window sizes changes macro F1 by -0.0476, -0.0000 and -0.0568 (LR, DT, RF); the largest drop (Random Forest, 0.0568) shows that part of the performance rests on these host-specific values. (d) SMOTE did not help: without any resampling macro F1 is +0.0044, +0.0051 and +0.0000 relative to SMOTE, and class weights do no better than no resampling. FTP-BruteForce is already perfectly separable, so synthetic FTP flows only add false alarms.

Improvement and model choice. I re-selected hyper-parameters by macro F1 instead of the saturated weighted F1. Its cross-validated macro F1 is optimistic by construction (it is the best of 20 settings), so the fair evidence is the test set, where macro F1 rose from 0.9666 to 0.9824 for Logistic Regression and from 0.9998 to 0.9999 for the Decision Tree (3 → 2 and 2 → 1 misclassified test flows); for the Random Forest both metrics select the same setting. Applying the rule fixed in advance, Random Forest has the highest cross-validated macro F1, Decision Tree is within one standard deviation, and Decision Tree is the fastest of the tied models (0.58 ms per 1,000 flows against 3.12 ms), so I select the Decision Tree (test macro F1 0.9999, FTP recall 1.00). Logistic Regression was selected with the symlog transform in both searches, and the single tree is the cheapest model to run and can be read as threshold rules (depth 6, 10 leaves).
