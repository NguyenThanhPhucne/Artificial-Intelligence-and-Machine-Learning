Test set (Steps 3–4). Every model detects all 9 FTP-BruteForce test flows and misclassifies between 0 and 3 of 15,000 flows (accuracy 0.9998–1.0000; Figures 5.1–5.2). Test macro F1 ranges from 0.9666 to 1.0000, and the test macro F1 of Random Forest, k-Nearest Neighbours and Support Vector Machine fall below one standard deviation of the cross-validated mean, yet every 95% bootstrap interval overlaps the cross-validated range. With nine FTP flows, one false alarm lowers macro F1 by about 0.02, so the test set cannot rank the models.

Improvement (Step 5). (i) Re-selecting hyper-parameters by macro F1 instead of the saturated weighted F1 changed the test errors of Decision Tree, Logistic Regression and Multi-layer Perceptron, with fewer errors for Decision Tree and Logistic Regression. (ii) L1 regularisation of Logistic Regression with C = 0.1 keeps 19 of 69 features at a cross-validated macro F1 of 0.9830, whereas L2 at the same C keeps all and scores 0.9671; the lasso therefore doubles as feature selection, and it keeps Fwd Seg Size Min. (iii) Adding Dst Port raises macro F1 beyond one standard deviation for 0 of 8 models: the models already reach the ceiling without it, so the port is excluded because it encodes the labelling (section 2.3.5), not because the models would need it. Removing the window sizes and Fwd Seg Size Min, which are constant within each attack and reflect the attacking hosts, lowers macro F1 by 0.01 or more for Gaussian Naive Bayes, k-Nearest Neighbours, Multi-layer Perceptron, Random Forest and Gradient Boosting (up to 0.171 for Gaussian Naive Bayes), but not for Decision Tree, Logistic Regression and Support Vector Machine. SMOTE helped beyond one standard deviation for no model; relative to SMOTE, no resampling changed macro F1 by -0.0051 to +0.0079 and Tomek links by -0.0051 to +0.0079: FTP-BruteForce is already separable, so synthetic flows mostly add false alarms. (iv) Correlation-based feature selection keeps 16 of 66 numeric features at the Week 5 lab's 0.7 cut-off and 39 at 0.95; macro F1 stays within one standard deviation of the main pipeline for 0 of 8 models at 0.7 and 8 of 8 at 0.95 (largest drop -0.1390, Gaussian Naive Bayes, at 0.7), so the lab's 0.7 cut-off removes information that 8 of 8 models need, whereas near-duplicate columns (0.95) can be dropped without measurable loss: a rank correlation of 0.7 between two flow statistics still leaves enough independent variation to separate the rare FTP flows.

Validation (Step 6). Without de-duplication 99.96% of FTP-BruteForce and 50.9% of SSH-Bruteforce test flows already occur identically in the training set, and the Random Forest scores 1.0000 macro F1 on that split, so a naive evaluation measures memory. The learning curves (Figure 5.4) show training and validation scores converging; the largest final gap is 0.0059 (Logistic Regression), and only Decision Tree still gains more than 0.005 from the last 20% of data. (d) On a day the models never saw (15 February 2018), benign traffic stays quiet: Decision Tree raises 3 false alarms on 20,000 benign flows (0.015%, 95% CI 0.005%–0.044%), and the eight models range from 0 (Random Forest, Gaussian Naive Bayes and Logistic Regression) to 3 (Decision Tree). None of the models was trained on DoS, and Decision Tree flags only 46% of DoS-GoldenEye and 1% of DoS-Slowloris flows as an attack (mostly as SSH-Bruteforce), so most unseen attack flows would be missed. Of the DoS flows Decision Tree flags, 98% carry the attacking hosts' initial window of 26,883 bytes (against 69% of all DoS flows), so its alarms on unseen attacks come mainly from recognising the attacking machines rather than the attack. Refitted without those columns, the tree still makes 2 test errors but flags 0% of DoS-GoldenEye and 0% of DoS-Slowloris: the alarms vanish, which confirms that they came from the hosts.

Comparison (Step 7). By the rule fixed in advance, k-Nearest Neighbours has the highest cross-validated macro F1 (0.99998) and no other model is within one standard deviation, so the final model is k-Nearest Neighbours (test macro F1 0.9999, 1 error, 34.12 ms per 1,000 flows). For deployment I recommend Decision Tree: within 0.01 macro F1 of the leader, its cross-validated accuracy does not depend on the attacking hosts' TCP values, and it runs in 0.60 ms per 1,000 flows.
