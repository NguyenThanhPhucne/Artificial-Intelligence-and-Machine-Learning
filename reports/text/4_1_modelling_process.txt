Every model is the same imbalanced-learn pipeline: Protocol is one-hot encoded; the numeric features pass through an optional symlog transform, a filter that drops constant columns and a StandardScaler; SMOTE then oversamples FTP-BruteForce; finally the classifier is fitted. Because imbalanced-learn applies SMOTE only during fitting, synthetic flows are generated from each training fold and never reach a validation fold. I first scored each algorithm with scikit-learn's default hyper-parameters and without SMOTE (Logistic Regression needed max_iter = 2,000 to converge). I then tuned each algorithm with RandomizedSearchCV: 20 settings × 5 stratified folds = 100 fits per model, with the SMOTE target size and neighbour count searched alongside the model parameters, and the best mean weighted F1 refitted on all 60,000 training flows. The selected settings were: Logistic Regression (C = 1.2229, numeric transform = symlog, SMOTE k_neighbors = 5, SMOTE sampling_strategy = 500 FTP flows); Decision Tree (criterion = entropy, max_depth = None, min_samples_leaf = 4, SMOTE k_neighbors = 5, SMOTE sampling_strategy = 1,000 FTP flows); Random Forest (max_depth = 20, max_features = log2, min_samples_leaf = 1, n_estimators = 113, SMOTE k_neighbors = 5, SMOTE sampling_strategy = 1,000 FTP flows). On an M1 Max (10 cores, folds in parallel) the searches took 30 s, 20 s and 176 s; refitting the selected model took 0.78 s, 0.47 s and 3.76 s, and inference took 1.23, 0.37 and 2.71 ms per 1,000 flows (Figure 4.1). Weighted F1 barely discriminated between settings: 7, 6 and 13 of the 20 settings scored within one standard deviation of the best.
