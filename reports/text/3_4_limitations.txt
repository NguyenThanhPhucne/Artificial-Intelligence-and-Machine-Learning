The dataset covers one day and two attack types, so the models learn to separate SSH and FTP brute force from that day's benign traffic, not intrusions in general. After de-duplication only 46 FTP-BruteForce flows remain (9 in the test set), so its per-class scores rest on very few examples and SMOTE can only interpolate between them. The labels were created from the attack schedule, ports and IP addresses, and both attacks share the same initial TCP window (26,883 bytes) set by the attacking machines, so a model may learn the labelling procedure or the attacking hosts rather than attack behaviour; I exclude Dst Port and Timestamp and test both shortcuts with ablations. The split is random, not by time or host: flows of the same attack session can fall in both partitions, which is optimistic, and this file contains no IP columns that would allow a host-grouped split. Finally, the file stops at the Excel row limit and may be truncated. Options include a time-based split, adding further CSE-CIC-IDS2018 days and attack types, and comparing with cost-sensitive learning (class weights) instead of SMOTE.
