Accuracy is not informative here: a classifier that never predicts FTP-BruteForce would still reach 99.94% accuracy on the training set. The brief requires weighted F1, which I use to select hyper-parameters, but weighted F1 is dominated by the Benign class (85% of flows). I therefore also report macro-averaged F1, precision and recall, in which every class counts equally, and the recall of FTP-BruteForce on its own, because a missed attack is the costliest error for an intrusion detector. Confusion matrices show which classes are confused and how many false alarms each model raises. All models are evaluated with the same 5-fold stratified cross-validation (shuffled with seed 42) on the training set, reported as mean ± standard deviation across folds; random rather than exhaustive search samples 20 settings per model at a fraction of the cost (Bergstra and Bengio, 2012). Out-of-fold predictions give a confusion matrix on "seen" data in which no flow is predicted by a model trained on it. I also time training and inference, because a detector on cloud infrastructure must keep up with traffic. The held-out test set is used once, for the final comparison in section 5.
