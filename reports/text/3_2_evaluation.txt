Accuracy is not informative here: a classifier that never predicts FTP-BruteForce would still reach 99.94% accuracy on the training set. I select hyper-parameters by weighted F1 but also report macro-averaged F1, precision and recall, in which every class counts equally, the recall of FTP-BruteForce, because a missed attack is the costliest error, and confusion matrices, which show how many false alarms each model raises. All models are evaluated with the same 5-fold stratified cross-validation (shuffled, seed 42) on the training set, reported as mean ± standard deviation. I stratify because with plain shuffled KFold a validation fold held between 4 and 9 FTP-BruteForce flows and with StratifiedKFold between 7 and 8, so every fold tests the rare class equally, although the spread of a default Decision Tree's macro F1 across folds did not shrink (cross_val_score standard deviation 0.0090 against 0.0070 for KFold): with seven FTP flows per fold, one error still moves the score, so I report the standard deviation alongside every mean. Out-of-fold predictions give a confusion matrix on "seen" data in which no flow is predicted by a model trained on it. I also time training and inference, because a detector on cloud infrastructure must keep up with traffic. The held-out test set is used once, in section 5.
