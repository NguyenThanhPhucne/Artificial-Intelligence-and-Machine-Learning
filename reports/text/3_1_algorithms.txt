The task is multi-class classification, so I compare eight classification algorithms from the module, chosen because each learns the decision boundary differently. A Decision Tree splits the data on single-feature thresholds, which matches the patterns found in the EDA and gives readable rules; a Random Forest averages trees grown on bootstrap samples, which reduces the variance of a single tree. Gaussian Naive Bayes applies Bayes' theorem under the assumption of independent, normally distributed features, which the strong redundancy found in the EDA violates. k-Nearest Neighbours classifies a flow by its closest training flows, so it depends on how features are scaled. Logistic Regression is the linear baseline: if it matches the trees, the classes are close to linearly separable. A Support Vector Machine finds the widest margin between classes, with a linear or RBF kernel. Gradient Boosting adds trees one at a time, each correcting the previous errors, and a Multi-layer Perceptron learns a non-linear representation of the inputs. All eight are implemented in scikit-learn (Pedregosa et al., 2011) inside one imbalanced-learn pipeline (Lemaître, Nogueira and Aridas, 2017).
