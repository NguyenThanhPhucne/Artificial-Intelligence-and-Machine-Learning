I split the 75,000-flow sample into a training set (60,000 flows, 80%) and a test set (15,000 flows, 20%) using a stratified split on Label with a fixed seed (random_state = 42). Stratification keeps the class proportions identical in both partitions (Benign 84.76%, SSH-Bruteforce 15.18%, FTP-BruteForce 0.06%), which matters most for FTP-BruteForce: only 46 unique FTP flows survived de-duplication, so the training set holds 37 and the test set 9. Because duplicates were removed before splitting, I could verify that no feature vector appears in both partitions (0 shared vectors, checked by hashing every flow). Every step that learns from data (exploration, constant-feature removal, scaling, SMOTE and hyper-parameter tuning) uses the training set only, inside 5-fold stratified cross-validation; the test set is used once, for the final evaluation. With 37 training flows, each fold trains on about 30 FTP flows and validates on about 7, so per-class scores for FTP-BruteForce will have high variance, and I report their spread across folds.
